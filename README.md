# Observatoire D4

Projet personnel non commercial pour explorer, par journée de D4, les apparitions de joueurs déjà vus en division supérieure.

L’interface actuelle utilise des données de démonstration. Certaines fiches comportent des liens documentaires ; cela ne constitue pas une analyse réglementaire.

## Sprint 1

Séparation de la page en HTML, CSS et modules JavaScript natifs, avec un serveur Node.js local et un stockage SQLite. Aucune dépendance externe prévue pour l’application.

Le collecteur `collecte_onze_lotois.py` est un outil indépendant. Il utilise Python et `lxml` et n’est pas exécuté par l’application.

Références : [langage visuel](design_language.md), [avancement](app-progress.md).
